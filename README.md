# HOI Business Center

React + Express app for HOI Business Center services, venues, packages, bookings, user auth, and admin management.

## Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Express REST API
- Database: MySQL locally; PostgreSQL is also supported for guideline-compliant deployments
- Auth: JWT with email/password, phone OTP, and verified signup email OTP

## Run Locally

```bash
pnpm install
cd backend
pnpm install
cd ..
docker compose -f docker-compose.mysql.yml up -d
npm run dev
```

Frontend:

```text
http://localhost:5173
```

Backend health:

```text
http://localhost:5000/api/health
```

## Database

Local database runs in Docker MySQL:

```text
container: hoi-business-mysql
database: hoi_business_center
port: 3307
```

Backend connection is configured in `backend/.env`:

```env
DB_CLIENT=mysql
DATABASE_URL=mysql://hoi_user:hoi_password@127.0.0.1:3307/hoi_business_center
```

Table creation comes from `backend/config/schema.js`. For PostgreSQL, set:

```env
DB_CLIENT=postgres
DATABASE_URL=postgresql://user:password@host:5432/database
DB_SSL=true
```

Seed/update catalog data:

```bash
cd backend
npm run init-db
```

## Quality Checks

Run frontend linting:

```bash
npm run lint
```

Run production build:

```bash
npm run build
```

Run API smoke tests after Docker MySQL and backend are running:

```bash
npm run test:api
```

Run the full local CI sequence:

```bash
npm run ci
```

## Admin

Admin panel manages:

- website users
- admins/editors
- page content
- venues and venue detail data
- services and packages
- event calendar
- manpower roles
- requirements/submissions
- theme colors
- venue image URL or direct image upload

## Notes

- `dist/` is generated by `npm run build` and is not stored as source.
- Uploaded admin/manpower files live under `backend/uploads`.
- Signup requires email verification before a user is created.

## Deployment

- Frontend: Vercel, using `vercel.json`.
- Backend: Railway/Render, using `railway.json`.
- CI/CD: GitHub Actions workflow in `.github/workflows/ci.yml`.

Required production environment variables:

```env
DB_CLIENT=postgres
DATABASE_URL=postgresql://user:password@host:5432/database
DB_SSL=true
JWT_SECRET=long-random-secret
FRONTEND_URL=https://your-frontend-domain.com
REQUIREMENT_EMAIL=team@example.com
EMAIL_USER=your-smtp-user
EMAIL_PASS=your-smtp-password
```
