Executive Summary

The current project is a full-stack HOI Business Center website with React/TypeScript frontend, Node.js/Express backend, PostgreSQL/Supabase database support, seeded catalog data, authentication, customer submission flows, and a restored admin dashboard. The website is ready for GitHub-based deployment after production environment variables are configured.

Deployment Requirements

Set these production environment variables before deployment:

  • NODE_ENV=production
  • PORT=3000 or host-provided port
  • FRONTEND_URL=https://your-domain.com
  • JWT_SECRET with a strong random value
  • ADMIN_EMAIL and ADMIN_PASSWORD
  • DB_CLIENT=postgres
  • DATABASE_URL=postgresql://... from Supabase/production PostgreSQL
  • DB_SSL=true for Supabase
  • REQUIREMENT_EMAIL, EMAIL_USER, EMAIL_PASS for emails

Final Notes
